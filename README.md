# 윤경이의 캠퍼스 미로

진윤경과 함께 커피 3잔을 모아 강의실에 도착하는 픽셀 미로 게임입니다.

**플레이:** https://dbsrud-cmd.github.io/yunkyung-campus-maze/

## 조작

- PC: 방향키 또는 WASD
- 모바일: 방향 버튼을 누르거나 길게 누르기, 미로 위에서 스와이프
- 커피 3잔을 모두 모은 다음 오른쪽 아래 강의실에 도착하면 성공
- 새로운 미로 버튼으로 다시 시작

휴대폰의 세로·가로 화면과 노치 영역에 대응하며, 동작 줄이기 설정을 지원합니다. `index.html`을 다운로드해 브라우저에서 직접 열어도 실행됩니다. 캐릭터 이미지는 HTML에 포함되어 있습니다. 웹 폰트는 인터넷 연결이 필요하며 오프라인에서는 시스템 글꼴로 표시됩니다.

## 개발 및 배포

빌드 도구 없이 `index.html`을 수정합니다. 게임 로직 검사는 `node check-game.cjs`로 실행합니다. GitHub Pages는 `main` 브랜치 루트에서 배포되며, 변경 사항을 푸시하면 배포가 갱신됩니다.

`assets/yunkyung-sprites.png`는 캐릭터 원본입니다. 생성 과정과 참고 자료는 `assets/ART-NOTES.md`에 기록되어 있습니다. 개인 재사용 스킬은 이 게임 저장소에 포함하지 않습니다.
